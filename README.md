### Featured Projects

- **ReconStream** (in progress) - Real-time trade reconciliation in Java and Kafka Streams. It normalizes JSON, FIX 4.4, and CSV trade feeds, matches them with exactly-once processing, and routes breaks and malformed messages to dead-letter topics, tested by a fault-injection simulator.
- **[Bullion-X](https://github.com/pranavb1924/bullionx)** - Stock portfolio simulator that streams Finnhub market data through Kafka to three Spring Boot microservices, deployed on AWS ECS Fargate with JWT auth.
- **[MindVault](https://github.com/pranavb1924/mindvault)** - Zero-knowledge journaling app (Spring Boot, PostgreSQL, Angular) that derives encryption keys on the client, so the server stores only ciphertext.
